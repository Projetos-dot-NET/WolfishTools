# 🐺 WolfishTools

![NuGet](https://img.shields.io/nuget/v/Wolfish.Maia)
![GitHub](https://img.shields.io/github/license/wolfishstudio/tools)

**WolfishTools** é um conjunto de ferramentas modernas para desenvolvedores **.NET**, focado em produtividade, automação e integração com modelos de linguagem (LLMs), oferecendo bibliotecas reutilizáveis e um CLI extensível.

O projeto é distribuído via **NuGet** e organizado de forma modular para facilitar manutenção, testes e evolução.

---

## 🚀 Principais Recursos

- 📦 Conjunto de bibliotecas .NET reutilizáveis
- 🧠 Integração com LLMs (Gemini, LLaMA)
- 💻 CLI próprio: **Wolfish.Maia**
- 🧩 Arquitetura modular
- ⚡ Foco em produtividade para desenvolvedores .NET

---

## 📦 Pacotes NuGet

| Pacote | Descrição |
|------|---------|
| `Wolfish.Core` | Núcleo de funcionalidades compartilhadas |
| `Wolfish.Shared` | Utilitários e abstrações comuns |
| `Wolfish.Commands` | Infraestrutura de comandos |
| `Wolfish.Gemini` | Integração com Google Gemini |
| `Wolfish.Llama` | Integração com modelos LLaMA |
| `Wolfish.Maia` | CLI principal do projeto |

> 🔎 Consulte o NuGet.org para versões e histórico de releases.
