Documentação do Wolfish Maia

Guia completo de comandos e funcionalidades da ferramenta

📋 Pré-requisitos

O Wolfish Maia requer o .NET 10 SDK instalado no seu sistema.

💻 Comandos Disponíveis

maia welcome
Exibe a mensagem de boas-vindas e status da assistente.
maia download qwen  |  maia download gemma
Baixa os modelos de linguagem locais (Qwen ou Gemma) para uso offline.
maia download chrome
Baixa o navegador/dependências necessárias para automações.
maia ask "sua pergunta aqui"
Envia uma pergunta diretamente para o modelo de linguagem local no terminal.
